### 👋 About me

I'm an AI & Data Science student at **Middle East University, Amman** (Class of 2027) who builds machine-learning projects **end to end**: clean the data, benchmark the models, then ship them behind an API, a UI and a `docker compose up`.

- 🧠 Deep learning with **PyTorch**: CNNs, transfer learning, neural collaborative filtering
- ⚙️ Production habits: modular code, containerized services, API keys, rate limits, error handling
- 🔧 Also builds hardware: a laser-cut, servo-driven sphere sorter with **>90% sorting accuracy**
